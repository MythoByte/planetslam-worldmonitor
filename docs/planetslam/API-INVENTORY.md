# Data integration, cost and permissions audit

Audit date: 2026-11-03. Baseline World Monitor 2.11.7, SHA in ARCHITECTURE.md. This is an engineering inventory, not blanket redistribution clearance. No paid account, provider credential, commercial contract or new terms acceptance was provisioned. Unknown quotas and rights remain blockers for public activation of that source.

The source-attribution manifest distinguishes reviewed entries, entries awaiting terms review, and excluded entries. Exclusions include transports, local/first-party services, and candidates. [SOURCE-HOSTS.md](SOURCE-HOSTS.md) records the original audit snapshot; consult the current shared source-attribution manifest for registry-derived totals. Upstream review does not establish MythoByte redistribution rights. The matrix below covers major provider families; long-tail sources retain per-host review gates, and current contracts or quotas have not all been independently verified.

Self-host column describes the **adapter/cache**, not permission to host the provider dataset or API. Refresh values are application polling from `src/config/variants/base.ts` or seeder declarations; they are not provider publication frequency or SLA. Cache loss can make routes return 503 until their upstream seeders run. Preserve stale/unknown labels.

## Primary sources checked live

- [USGS GeoJSON documentation](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php): summary cadence and format.
- [Open-Meteo terms](https://open-meteo.com/en/terms): non-commercial free endpoint, numeric quotas and CC BY data distinction.
- [RainViewer API](https://www.rainviewer.com/api.html): permitted use, attribution and commercial contact requirement.
- [ACLED terms](https://acleddata.com/terms-and-conditions): EULA, content usage and attribution are separate conditions.
- [Alpha Vantage support](https://www.alphavantage.co/support/): current default free quota and premium exchange data caveat.
- [NASA FIRMS area API](https://firms.modaps.eosdis.nasa.gov/api/area/): free MAP_KEY, transaction accounting and 5,000/10m quota.
- [FRED API key documentation](https://fred.stlouisfed.org/docs/api/api_key.html): API-key requirements, including application/user conditions.

Other matrix entries are source-code/upstream-document observations requiring current provider confirmation before public activation. No fee amount is budgeted because this prototype has no paid service dependency. Optional AI, commercial news, aviation/maritime, market redisplay and weather services must be costed and approved separately. Free-tier quotas may be too low for upstream's configured refresh rates. Run shared caches, honor Retry-After and retain upstream backoff; never multiply provider polling per public visitor.
